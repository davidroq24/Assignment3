2. Design Rationale

Why I Chose Matter.js

For this assignment, I wanted to build a small interactive game without using a heavy 3D engine like Three.js or A-Frame. Coding gravity, bouncing, and block collisions from scratch in plain JavaScript takes a lot of math and time, so I chose Matter.js, a lightweight 2D physics library.

This prototype shows a few things Matter.js handles well out of the box:

  • Slingshot Physics: Using Matter.Constraint, I attached the boulder to a giant wooden slingshot so users can pull and release it with elastic tension.
  • Realistic Castle Collisions: Each stone wall, wooden beam, and tower roof has its own weight and friction, so hitting the base naturally collapses the upper towers.
  • Custom Canvas Rendering & Live Gravity: By pairing Matter.js's physics engine with a custom HTML5 canvas loop, I layered stone textures, a flying background dragon that never interferes with physics collisions, and real-time gravity controls.

Opportunities Beyond This Prototype

Right now this is just a single-screen sandbox, but it could easily grow into a full browser game or interactive learning tool:

  • Levels and Scoring: By listening to Matter.js collision events, I could track when the golden royal crest falls to the ground, keep a real score, and load harder castle layouts.
  • Custom Sprites and Sound: Instead of procedural canvas shapes, Matter.js allows loading PNG sprite sheets and adding stone-crumbling sound effects using the Web Audio API.
  • Physics Learning Demos: A similar setup could be used on educational websites so students can test how mass, gravity, and launch angles affect projectile motion.
