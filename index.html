2. Design Rationale

Why I Chose Matter.js

For this assignment, I wanted to build a small interactive game without using a heavy 3D engine like Three.js or A-Frame. Coding gravity, bouncing, and block collisions from scratch in plain JavaScript takes a lot of math and time, so I chose Matter.js, a lightweight 2D physics library.

This prototype shows a few things Matter.js handles well out of the box:

  • Slingshot Physics: Using Matter.Constraint, I attached the projectile to a fixed point so users can pull and release it like an elastic band.
  • Realistic Collisions: Each block has its own weight, friction, and bounce settings, so hitting the bottom row naturally knocks down the rest of the stack.
  • Live Gravity Controls: By updating engine.gravity.y with simple buttons, the player can switch between normal Earth gravity, low Moon gravity, or floating zero-gravity in real time.

Opportunities Beyond This Prototype

Right now this is just a single-screen sandbox, but it could easily grow into a full browser game or interactive learning tool:

  • Levels and Scoring: By listening to Matter.js collision events, I could track when the yellow target block hits the ground, keep a real score, and load harder block layouts.
  • Custom Graphics and Sound: Instead of basic colored shapes, Matter.js allows replacing blocks with custom PNG sprites and adding impact sound effects using the Web Audio API.
  • Physics Learning Demos: A similar setup could be used on educational websites so students can test how mass, gravity, and launch angles affect motion.
