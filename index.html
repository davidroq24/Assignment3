Design Rationale

Why I Chose Matter.js

I wanted to build a small playable game for this prototype without using heavy 3D frameworks like Three.js or A-Frame that we already covered in class. Writing polygon collisions, rotation, and bouncing from scratch in plain JavaScript takes a lot of vector math, so I chose Matter.js, a lightweight 2D rigid-body physics library.

This demo focuses on three features Matter.js handles out of the box:

  • Multi-Sided Polygon Physics: Using Matter.Bodies.polygon() with six sides, the grey moon rocks stack, tumble, and roll naturally when struck by the yellow orbs.
  • Custom Cartoon Canvas Loop: Stepping the physics simulation with Matter.Engine.update() inside a standard HTML5 canvas loop let me draw a cartoon astronaut, Earth in the background, and cratered lunar ground over the physics bodies.
  • Live Gravity Switching: Changing engine.gravity.y with the toolbar buttons lets players immediately compare low lunar gravity against Earth gravity and near-zero gravity.

Opportunities Beyond This Prototype

Right now this is a single sandbox stage, but the same setup could expand into a fuller web project:

  • Ammo Limits and Star Ratings: Checking how many hexagonal rocks get knocked off the platform would make it easy to add a limited orb count per round and unlock harder stages.
  • Sound Effects and Dust Particles: Listening to Matter.js collisionStart events could trigger retro Web Audio sound effects and small dust puffs on impact.
  • Interactive Science Demos: A visual setup like this works well for introductory physics pages where students can test launch angles and planetary gravity hands-on.
